PiTrex new menu @VERSION@: where each program in payload/ comes from

Source: https://github.com/emmulator/pitrex-baremetal, branch menu-redesign (a fork of
https://github.com/malbanGit/pitrex-baremetal). Compiler: gcc-arm-none-eabi 10.3.1 (Ubuntu 22.04 package),
built with new_menu/tools/build.sh. Each file exists for both Pi models (piZero1/ = Pi Zero W, piZero2/ = Pi Zero 2).

| Files | Built from |
|---|---|
| pitrex.img, pitrex7.img, loader.pit, aae.img | fork commit @COMMIT@ (the new menu, the AAE game picker) |
| vectrexexact.img, vectrexspeedy.img | the fork; emulator code unchanged from upstream c44e5e4 (2025-05-24) |
| vectrexvideo.img, vectrexaudio.img, vectrexlineart.img, vectorblade.img | the fork, 2026-10-17; no source changes (Malban's July 2025 images show a blank screen on a Pi Zero W) |
| swsbt.img, tempest.img | the fork, 2026-10-17; no source changes (same reason) |
| blackwidow.img | the fork, 2026-10-17; one-controller fire (sim/vx_interface.c, commit 0cb4a60) |

menu/menu.default.ini is generated by new_menu/tools/entries_to_menu_ini.py from new_menu/menu/sidecar/menu (made by
export_sidecars.py, more_sidecars.py and controls_sidecars.py).
